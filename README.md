# 📈 Stock Portfolio Tracker

A simple Python-based Stock Portfolio Tracker developed as part of the CodeAlpha Python Programming Internship.

## 🚀 Features

- Displays available stocks and their prices
- Allows users to enter stock symbols
- Accepts stock quantity
- Calculates individual investment
- Calculates total portfolio investment
- Displays portfolio summary
- Saves the portfolio report to a text file

## 🛠️ Technologies Used

- Python
- Dictionary
- Loops
- Conditional Statements
- Input/Output
- File Handling
- Basic Arithmetic
